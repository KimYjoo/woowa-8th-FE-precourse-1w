# javascript-calculator-precourse

> # 과제 정의
- 문자열에서 구분자를 기준으로 숫자를 추출하고 모두 더하라
- 구분자 ⇒ 쉼표 or 콜론
- 커스텀 구분자 ⇒ 문자열 앞부분”//” 뒷부분”\n” 커스텀 구분자로 사용
- 사용자가 잘못된 값을 입력할 경우 “[ERROR]” 로 시작하는 메시지와 함께 Error 발생, 애플리케이션 종료
<br>
<br>
<br>

# 구현 전
### 제시된 요구사항 외적으로 고려한 점
##### 커스텀 구분자의 개수?
    1. 1개만 가능할때
        - 기존 방식 사용

    2. 1개 이상 가능할때
        (1) ‘//’ 와 ‘\n’ 사이에 여러 문자를 합쳐서 받기
        (2) ‘//’와 ‘\n’ 사이에 하나의 문자만 오고 여러개 작성해서 받기
        
        ⇒ 그렇다면 커스텀 구분자를 중복 입력했을 경우엔?
            1. 무시하기
            2. 에러
##### 커스텀 구분자의 제한사항?
    - 구분자는 숫자가 아니여야한다.
    - '4:,:6' 처럼 숫자 사이 여러 구분자가 입력된 경우
    - 커스텀 구분자를 정의할때 필요한 ‘/’ 및 ‘\’ 에 대한 대책이 필요 (사용은 가능)
    - ' ' 공백을 나타내는 스페이스 문자도 구분자로 사용가능
    - // 와 \n 사이에 아무것도 없을 경우엔?
        1. 무시하기
        2. 에러
##### 사용자 입력 오류의 종류?
    - 문자열에 숫자가 없을 경우
    - 기본 및 커스텀 구분자가 아닌 기호를 사용할 경우
<br><br>

### 요구사항 결론
- 문자열에서 구분자를 기준으로 숫자를 추출하고 모두 더하라
    - 구분자는 하나의 기호로 이루어져있다.
    - 숫자 사이에 여러 개의 구분자를 입력해도 하나의 구분자로 인식한다.
    - 기본 구분자 = 쉼표 ","  콜론 ":"
    - 커스텀 구분자 = 입력 문자열 앞부분에 ”//” 와 \n”의 사이에 있는 문자
        - 커스텀 구분자는 숫자일 수 없다
        - 2개 이상의 커스텀 구분자 입력 시 "//" 와 "\n" 사이에 나열
        - ' ' 공백 문자도 구분자로 포함된다.
        - 구분자 중복입력 시 하나로만 처리된다.
<br><br>

- 사용자가 잘못된 값을 입력할 경우 “[ERROR]” 로 시작하는 메시지와 함께 Error 발생, 애플리케이션 종료
    - 아무값도 입력하지 않았을 경우 
    - 입력 문자열에 숫자가 없을 경우
    - 커스텀 구분자를 등록하기 위한 문자가 틀렸을 경우
    - 커스텀 구분자가 숫자일 경우
    - 기본 및 커스텀 구분자가 아닌 문자가 존재할 경우

### 기능 요구사항 체크리스트

#### 사용자 입력
- [ ] 입력 안내 메시지 `덧셈할 문자열을 입력해 주세요.`를 출력한다.<br>
- [ ] 사용자가 문자열을 입력한다.<br>
<br>

#### 입력처리
- [ ] 입력된 문자열에 숫자가 포함되어 있는지 검증한다.<br>
- [ ] 커스텀 구분자가 정의되어 있는지 검사한다<br>
    - [ ] 커스텀 구분자가 정의되어 있다면, 내부에 있는 문자열을 문자 한개씩 나누어 커스텀 구분자로 등록한다.<br>
    - [ ] 커스텀 구분자가 숫자일 경우 에러<br>
    - [ ] 커스텀 구분자 정의문을 입력 문자열에서 제거한다.<br>
- [ ] 기본 및 커스텀 구분자를 기준으로 문자열을 나눈다. <br>
    - [ ] 분리된 문자열 단위를 숫자형으로 변환하여 결과 값에 합한다.<br>
    - [ ] 숫자형으로 변환되지 않을 경우 에러 <br>
<br>

#### 결과 출력
- [ ] 모든 숫자를 더한 값을 `결과 : [결과값]`와 같은 형식으로 출력한다.<br>
